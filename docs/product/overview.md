# Work Sharing Dashboard

한 팀이 역할 사이에 작업을 넘기며 진행 상황을 보는 웹 대시보드.

## v1 범위

- 팀 하나. 로그인 계정은 이메일과 비밀번호.
- 작업: 제목, 설명, 담당 역할, 상태, 마감일, 선행 작업, 인수 메모.
- 역할: 기획, 디자인, 퍼블리싱, 프론트엔드, 백엔드.
- 상태: 대기, 진행, 검토, 완료.
- 화면: 보드, 역할 필터, 작업 상세, 인수 메모 작성.
- API는 JSON. 화면 문구는 한국어.

## 역할이 만드는 산출물

| 역할 | 경로 | 산출물 |
| --- | --- | --- |
| 기획 | `docs/planning/` | 사용자 흐름, 화면 목록, 작업 필드, 인수 조건 |
| 디자인 | `design/` | 화면 구성, 토큰, 상태별 UI |
| 퍼블리싱 | `apps/web/markup/` | 시맨틱 HTML과 CSS. 동작 로직 없음 |
| 프론트엔드 | `apps/web/src/` | 마크업을 따르는 React 화면과 API 연동 |
| 백엔드 | `apps/api/` | 인증과 작업 API, 데이터 저장 |

## 기본 기술

- 웹: React, TypeScript, Vite
- API: Node.js, TypeScript, JSON
- 퍼블리싱 결과물이 시각 기준이다. 프론트엔드는 그 간격을 메운다.

## v1에서 하지 않음

모바일 앱, SSO, 결제, 알림 발송, 파일 첨부, 다중 조직.
