# 상품정보고시 이미지 생성 툴 — 개발 사양서

- 기준 디자인: Figma `셰프애찬` 파일(키 `fZfX5aalvG1rGlMZSsshoD`), 페이지 `🌟ai 자동화 상세페이지 양식`, 프레임 **`235:291`** (레이어 이름 `r.jpg`)
  https://www.figma.com/design/fZfX5aalvG1rGlMZSsshoD/?node-id=235-291
- 작성: 2026-10-26, Figma 값 그대로 옮김. **이 문서와 Figma 가 다르면 Figma 가 우선.**
- 예시 내용: 청양맵짤이(860×2553)

## 1. 툴이 하는 일

작업자가 상품의 고시 항목(제품명·원료명·내용량 …)과 주의사항, 영양정보를 입력하면 상세페이지용 **상품정보고시 이미지(JPG) 한 장**을 만든다. 같은 입력으로 **이미지 alt 문장**과 **관리자 '상품정보제공고시' 탭 값**도 함께 만든다(10장).

- 글은 **입력 원문 그대로** 쓴다. 맞춤법을 고치거나 문장을 지어내지 않는다(법적 표기).
- 행 높이는 내용 길이에 따라 늘어난다(원료명처럼 긴 칸은 여러 줄).

## 2. 입력

| 칸 | 필수 | 예(청양맵짤이) | 메모 |
|---|---|---|---|
| 제품명 | ○ | 청양맵짤이 | |
| 원료명 | ○ | 청양고추(국산), 대두유{대두(외국산:미국, 아르헨티나, 브라질 등)}, 혼합조미베이스{…}, 백설탕, L-글루탐산나트륨(향미증진제)}, 멸치(국산), 마늘(국산), 볶은참깨가루 | **원문 그대로**. 쉼표 뒤에만 띄어쓰기 |
| 알레르기 | | 대두, 소고기, 우유, 밀 | 원료명 끝에 `. {알레르기} 함유` 로 붙여 표시 |
| 내용량 | ○ | 225g, 365g, 500g, 3,220g | 여러 개면 쉼표 |
| 식품유형 | ○ | 조림류(가열하지 않고 섭취하는 냉동식품) | |

| 소비기한 | ○ | 상품에 별도 표시 | |
| 품목번호 | ○ | 2023031316622 | 품목제조보고번호. 13~14자리 모두 있음 |
| 제조원 | ○ | 셰프애찬에프(F)3 \| 대전광역시 동구 계족로 344 | 이미지에는 `업체 \| 주소` 그대로 |

| 영양정보 행 | | 성분 · 함량 · 비율 | 비율이 없으면 `-` (예: 열량, 트랜스지방) |
| 영양정보 안내 | | 1일 영양성분 기준치에 대한 비율(%)은 2,000kcal 기준이므로 개인의 필요 열량에 따라 다를 수 있습니다. | 기본값으로 채움 |

- 영양정보 행 기본 순서(식약처 표기 순): 열량 · 나트륨 · 탄수화물 · 당류 · 지방 · 트랜스지방 · 포화지방 · 콜레스테롤 · 단백질 (9행).
- 영양정보가 없는 상품은 영양정보 묶음(5-3) 전체를 뺀다. 주의사항이 없으면 주의 목록(5-2)을 뺀다.
- 함께 파는 다른 상품이 있으면 고시를 하나 더 만든다(이미지 한 장 = 상품 하나).

## 5. 섹션 상세

### 5-0. 제목
`상품정보고시` · Bold 52 · 줄높이 130% (68px) · 자간 -3% · #111111 · 가운데.

### 5-1. 고시 표 (table)
- 표: 폭 720, 세로 쌓기(간격 0), **위 테두리 2px #111111**(나머지 변 없음).
- 행 8개(순서 고정): 제품명 · 원료명 · 내용량 · 식품유형 · 보관방법 · 소비기한 · 품목번호 · 제조원.
- 행: 가로 배치, 안쪽 여백 16(사방), 간격 24, 위쪽 정렬, **아래 테두리 1px #e5e5ec**.
  - 항목명 칸: 폭 **110 고정**, Bold 28, 줄높이 140%(39px), 자간 -2%, #111111, 왼쪽.
  - 내용 칸: 나머지 폭 채움(554), Medium 26, 줄높이 165%(43px), 자간 -1.5%, #555555, 왼쪽, 자동 줄바꿈.
- 한 줄 행 높이 = 16 + 43 + 16 + 1 = **76**. 여러 줄이면 43px 씩 늘어남(예 원료명 6줄 = 291).
- 줄바꿈은 **낱말 단위**(한국어 keep-all). 단, 낱말 하나가 칸보다 길면 쉼표 뒤에서 끊고, 그래도 넘치면 글자 단위로 끊어 **칸 밖으로 넘치지 않게**(실제로 원료명이 칸을 넘었던 버그가 있었음).

### 5-2. 주의사항 (notes)
- 세로 쌓기, 항목 간격 10.
- 항목: 가로 배치, 간격 7. `※` 칸 폭 24 고정 + 글 칸 나머지(689) 채움.
- 글: Medium 24, 줄높이 170%(41px), 자간 -1.5%, #555555, 자동 줄바꿈(둘째 줄부터 `※` 다음 위치에 맞춰 들여쓰기 — 칸이 나뉘어 있어 자연히 그렇게 됨).
- 예: 3줄 항목 123, 2줄 82, 1줄 41.

### 5-3. 영양정보
- 세로 쌓기, 간격 12.
- 제목 `영양정보 (100g당)`: Bold 28, 줄높이 140%, 자간 -2%, #111111, 왼쪽.
- 영양 표(nutrition-table): 폭 720, **위 테두리 2px #111111**.
  - 머리 행(72): 안쪽 여백 위16·좌우24·아래16, 아래 테두리 1px #e5e5ec. 3칸 같은 폭(각 224): `영양성분`(왼쪽) · `함량`(오른쪽) · `1일 기준치 비율`(오른쪽) — Bold 28, #111111.
  - 성분 행(76): 같은 여백·테두리, 3칸 같은 폭.
    - 성분명: Medium 26, #111111, 왼쪽
    - 함량: Medium 26, #111111, 오른쪽 (예 `1,900mg`)
    - 비율: 값이 있으면 **Bold 26 #f97316**(orange/500), 없으면 `-` Medium 26 #555555. 오른쪽.
  - 예: 머리 72 + 9행 × 76 + 위 선 2 = 758.
- 안내(nutrition-note): 항목 가로 배치 간격 10, `※` 칸 폭 20 고정 + 글 채움. Medium 26, 줄높이 165%, #555555.

## 7. 글꼴
**Noto Sans KR** (Medium 500 / Bold 700). 웹 렌더: Google Fonts `Noto+Sans+KR:wght@500;700`. 자간 %는 글자 크기 대비. 띄어쓰기 폭 보정(Edge 렌더 시 `word-spacing: -0.045em`)은 기존 구현과 같게.

## 8. 표기 규칙 (입력 정리)

- 쉼표 뒤 띄어쓰기 1칸으로 통일(숫자 천 단위 쉼표 `3,220g` 은 제외).
- 원료명 괄호 구조는 바꾸지 않는다.
- 알레르기: 원료명 끝에 `. 대두, 소고기, 우유, 밀 함유`.
- 온도 `°C` → `℃`.
- 주의 문구의 `※` 는 입력에서 빼고 툴이 붙인다.
- 영양 함량은 단위 포함 원문(`160kcal`, `1,900mg`, `1.1g`), 비율은 `95%`.

## 9. 처리 순서

1. 입력 폼(또는 붙여넣기 텍스트 → 항목 자동 분리) → 8장 규칙으로 정리 → 미리보기.
2. 4~7장 디자인으로 렌더(HTML+CSS → 헤드리스 브라우저 캡처 권장).
3. 결과 JPG 저장 + 10장 alt·고시 값 함께 출력(복사 버튼).
4. 검수(11장) 후 작업자가 FTP 업로드·관리자 입력.

## 10. 함께 만드는 값

### 10-1. 이미지 alt (셰프애찬 alt 규칙: 긴 내용도 alt 하나에)
형식: `{제품명} 상품정보고시 및 영양정보 - 제품명: … / 원료명: … / 내용량: … / 식품유형: … / 보관방법: … / 소비기한: … / 품목번호: … / 제조원: {업체}, {주소} / {주의1} {주의2} … / 영양정보 (100g당): 열량 160kcal, 나트륨 1,900mg (95%), … / 1일 영양성분 기준치에 대한 비율(%)은 …`
- 영양정보가 없으면 이름은 `{제품명} 상품정보고시`.
- alt 안의 제조원은 `|` 대신 쉼표.
- 주의사항은 `※` 빼고 문장 그대로 띄어쓰기로 잇는다.
