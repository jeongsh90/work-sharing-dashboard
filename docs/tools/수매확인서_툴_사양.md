## 1. 툴이 하는 일

작업자가 **PDF 한 개(수산물 수매확인서)를 올리면**, 상세페이지에 넣을 이미지 `v.jpg` 한 장을 만든다.

1. PDF **첫 장**을 JPG 로 변환한다(내용은 절대 고치지 않음).
2. 정해진 디자인의 **이미지 영역(A4 종이 620×877)** 에 그 JPG 를 넣는다.
3. PDF 에서 두 곳을 찾아 **강조**를 얹는다.
   - `생식용 굴` 글자 → 주황 형광펜 + 아래 말풍선 `생식용 굴`
   - 표 첫 칸(생산일자 칸) → 그 칸을 덮는 말풍선 `수매일자 / MM.DD` (날짜 = PDF 의 **발행일**)
4. 결과 JPG 를 3개 상품의 업로드 경로 이름으로 저장한다.

나머지(제목·설명·배경)는 고정이다.

## 7. 동적 위치 계산 (핵심)

모든 계산은 **PDF 를 가로 2480px(A4 300dpi) 로 렌더한 이미지 좌표**로 하고, 마지막에 `s = 620 / 페이지폭(2480)` 를 곱해 paper 좌표로 바꾼다.

### 7-1. PDF → 이미지
- 첫 장을 가로 **2480px**, 세로는 비율대로(A4 = 3507), **흰 배경**으로 렌더 → JPG(품질 95) = pdf-image.
- 같은 이미지로 **한국어 OCR** → 줄·낱말과 낱말 상자(x, y, w, h).

### 7-2. 발행일 → 말풍선 날짜
- OCR 줄 중 `발행` 이 들어간 줄에서 `(\d{4})\s*\.\s*(\d{1,2})\s*\.\s*(\d{1,2})` → 날짜.
- 표시: `MM.DD` (두 자리, 예 `10.23`).
- 못 읽으면 작업자에게 날짜 입력을 받는다(입력 칸). 작업자가 직접 날짜를 주면 그 값이 우선.
- 참고: 표 첫 칸에는 '생산일자'(예 10.22)가 있지만, 디자인 결정상 말풍선은 **'수매일자' = 발행일**을 쓴다.

### 7-3. '생식용 굴' 형광펜
1. 낱말이 `생식용` 으로 시작하고 그 줄에 `증명` 이 있는 것(없으면 첫 `생식용`) = w1.
2. 같은 줄에서 w1 바로 오른쪽 낱말 w2. w2 가 `굴` 로 시작하면 형광펜 오른쪽 끝 = `w2.x + w2.w / w2글자수` (굴 한 글자까지), 아니면 `w1.x + w1.w`.
3. 형광펜(이미지 좌표) = 왼쪽 `w1.x − 8`, 위 `w1.y − 10`, 오른쪽 `위 끝 + 8`, 아래 `w1.y + w1.h + 10` → × s.
4. 못 찾으면 실패로 알리고 저장하지 않는다(또는 7-6 기본 위치 + 경고).

### 7-4. '생식용 굴' 말풍선 + 연결
- 말풍선(164×50): 왼쪽 = `형광펜 가운데 − 82`, 위 = `형광펜 아래 + 14`.
- 연결 사다리꼴: 꼭짓점 `(형광펜.왼, 형광펜.아래)`, `(형광펜.오른, 형광펜.아래)`, `(말풍선.왼+157, 말풍선.위)`, `(말풍선.왼+7, 말풍선.위)`.

### 7-5. '수매일자' 말풍선 = 표 첫 칸 덮기
1. 표 머리 낱말 찾기: `^(중량|품목|수량)` 으로 시작하는 낱말 hd (주의: `해역` 은 본문 '해역에서'와 겹치므로 쓰지 않음).
2. hd 와 같은 줄(세로 차이 < 40px) 낱말 중 가장 왼쪽 = 첫 칸 머리 c1 (예 `생산일자`).
3. 이미지를 흑백으로 보고 **밝기 < 120 = 선**으로 판단해 칸 테두리를 찾는다.
   - 왼선 L: c1 세로 가운데 높이에서 c1 왼쪽부터 왼쪽으로 첫 어두운 점
   - 오른선 R: 같은 높이에서 c1 오른쪽부터 오른쪽으로 첫 어두운 점
   - 윗선 T: c1 가로 가운데에서 c1 위쪽부터 위로 첫 어두운 점
   - 아랫선 B: **x = L + 10**(칸 안 왼쪽, 글자 피함)에서 c1 아래부터 내려가 첫 어두운 줄(가운데 선)을 지나, 그다음 어두운 줄
     (가운데 x 로 내려가면 날짜 글자 '10.22' 를 선으로 잘못 읽는다 — 실제로 겪은 버그)
4. 말풍선(164×112): 오른쪽 = `R × s + 4` → 왼쪽 = 오른쪽 − 164, 위 = `((T + B) / 2) × s − 56` (표 두 줄의 세로 가운데).

### 7-6. 기준값 (시험 PDF `수매확인서 261023.pdf` 결과 = Figma 값)
paper 좌표, 1배:

| 요소 | x | y | w | h |
|---|---|---|---|---|
| highlight | 79 | 422 | 67 | 19 |
| wedge 상자 | 31 | 441 | 164 | 14 |
| tag 생식용 굴 | 31 | 455 | 164 | 50 |
| tag 수매일자 | 11 | 527 | 164 | 112 |

## 8. 처리 순서 (툴 흐름)

1. PDF 업로드 → 쪽수 확인(2쪽 이상이면 경고, 첫 장 사용).
2. 7-1 렌더 + OCR.
3. 7-2 날짜(미리보기에 표시, 작업자가 고칠 수 있게).
4. 7-3~7-5 위치 계산. 하나라도 못 찾으면 어떤 것을 못 찾았는지 보여 주고 멈춘다(수동 위치 조정 UI 가 있으면 더 좋음).
5. 3~6장 디자인으로 860×1429 를 2배 렌더 → JPG q92.
6. 미리보기 → 작업자 확인 → 2장 출력 경로 3곳 + out/{날짜}/ 에 저장.

## 9. 검수 체크리스트

- [ ] 결과 크기 1720×2858 (1배 860×1429)
- [ ] PDF 내용이 바뀌거나 잘리지 않음(A4 620×877 꽉 채움, 비율 유지)
- [ ] 형광펜이 `생식용 굴` 글자(굴 한 글자까지)만 덮고, 글자가 비쳐 보임(곱하기 30%)
- [ ] `생식용 굴` 말풍선이 형광펜 가운데 아래, 연결 사다리꼴이 둘을 잇는다
- [ ] 수매일자 말풍선이 표 첫 칸(생산일자 머리+값)을 완전히 덮고, 표 아래 선이 말풍선 밖으로 비치지 않음
- [ ] 말풍선 날짜 = PDF 발행일 MM.DD
- [ ] 제목 72 Bold('안심' 주황), 설명 2줄·강조 주황
- [ ] 이미지 영역 패턴 배경, 종이 위아래 80
- [ ] 3개 파일 이름·경로 정확

## 10. 주의 · 알려진 점

- 같은 파일 이름으로 덮어쓰면 고객 브라우저 캐시로 며칠 예전 이미지가 보일 수 있다(상세설명 이미지 주소 끝 `?v=날짜` 로 해결 — 관리자 수정 필요, 툴 범위 밖).
- PDF 양식(발행처)이 바뀌면 OCR 위치 규칙(7-3, 7-5)을 다시 확인해야 한다. 지금 기준 양식: `고은수산` 발행, 표 열 = 생산일자 · 품목 · 수량 · 중량(kg) · 채취해역.
- OCR 은 `채취해역`을 `재취해역`으로 읽는 등 오타가 있을 수 있다. 위치 찾기에만 쓰고 글자는 이미지에 손대지 않는다.
